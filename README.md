# oh-my-grid — 릴리스 배포

[oh-my-grid](https://github.com/Canine89/oh-my-grid) 의 **배포 전용** 저장소입니다.
소스 코드는 비공개 저장소에 있고, 여기에는 빌드 결과물과 Sparkle 업데이트 피드만 둡니다.

- `appcast.xml` — Sparkle 업데이트 피드. 앱이 익명으로 받아야 해서 이 저장소만 공개입니다.
- Releases — 설치용 `.dmg` 와 업데이트용 `.zip`

## 설치

[Releases](../../releases/latest) 에서 `oh-my-grid-x.x.x.dmg` 를 받아
`oh-my-grid` 를 `Applications` 폴더로 드래그하세요.
첫 실행 시 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 권한을 켜야 합니다.

설치 후에는 앱이 자동으로 업데이트를 확인합니다.
